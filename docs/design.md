# Visual direction

Selected reference: **AgentSims**, with top-down cutaway rooms, selectable pixel characters and readable context panels. This is an adaptation, not a pixel-for-pixel clone of its research composite. No AgentSims source or art is shipped.

The office is the focal point; detailed work opens in regular conversation, document, task and team interfaces.

- Palette: slate #233949 navigation, forest #456e58 actions, white paper, #f5f6f3 gray-green background, #b76c45 wood accent, #263b49 ink.
- DM Sans wordmark/Latin, Noto Sans SC plus system fallbacks. No pixel typeface for long text.
- Desktop: 214px navigation, 69px project bar, map plus meeting/activity rail. Mobile: five bottom destinations, stacked content.
- Original 16-bit house with continuous corridor, studio, meeting room, library and workshop. Transparent sprite sheet of six residents.
- Room clicks open actual project views; characters reveal identity/status. Fixed selectable positions in v0.1, not free walking/pathfinding.
- Visible keyboard focus, native controls, named buttons, trapped dialog focus, Escape to close, explicit status text and reduced-motion support. Mobile navigation provides alternatives to small map labels.

UI/UX Pro Max matched Pixel Art. Its generic hero-centric marketing layout and neon palette did not fit this application; the selected spatial reference guides the hierarchy instead.

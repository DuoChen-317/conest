# 统一 AI 接入（2026-10-27）

主入口统一为“连接 AI → 复制接入提示词”。用户把提示词发给自己正在使用的本地 AI 客户端，由客户端安装接入助手、完成配对和 MCP 配置。用户不需要选择 HTTP / MCP、填写长期凭证、编辑 JSON 或先理解轮询频率。原有手动配置、自动问答连接器参数和本地目录设置保留在折叠的高级设置中。

## 用户流程

1. 在项目里创建 AI 身份，或打开自己 AI 卡片的“连接 AI”。点击“复制接入提示词”。
2. 将提示词发给支持本地执行与 MCP 的 AI 客户端。客户端检查运行环境、下载接入助手并校验 SHA-256，通过 stdin 提交配对数据。
3. 客户端显示八位凭证指纹。用户回网页核对同一个指纹，再点击“确认连接”。确认前，客户端生成的凭证无权调用任何项目接口。
4. 客户端保存本机配置并注册本地 stdio MCP，执行真实的初始化、工具发现和 `get_project` 身份验证。网页收到 MCP 请求后显示“已收到 MCP 客户端连接”。

提示词十分钟有效。刷新提示词会取消此前尚未批准的申请，已批准的其他连接不受影响。关闭面板或刷新网页后，重新打开同一个 AI 的连接入口可以恢复最近的申请和确认状态；不会从服务端恢复配对码或长期凭证明文。复制失败时可展开提示词手动复制。

当前接入助手验证的运行环境是 macOS / Linux、Node.js 18+。客户端的配置命令和是否需要重新载入，以其实际版本为准；不支持本地 MCP 的客户端需要明确报告限制。没有实际验证某客户端时，不应只根据模板声称它已安装或上线。

## 调研依据与选择

- [Codex 官方 MCP 文档](https://learn.chatgpt.com/docs/extend/mcp)支持本地 stdio 和远程 HTTP；CLI 可通过 `codex mcp add … -- …` 注册本地服务。
- [Claude Code 官方 MCP 文档](https://code.claude.com/docs/en/mcp)同样支持 stdio / HTTP，但客户端配置字段存在差异。例如 JSON URL 条目可能需要显式 `type`，不适合让普通用户抄同一份远程配置。
- [Codex 非交互执行](https://learn.chatgpt.com/docs/non-interactive-mode)和 [Claude Code 程序化执行](https://code.claude.com/docs/en/headless)提供各自的运行方式；这些能力仍需要真实执行进程，MCP 配置本身不等于后台模型调度。

据此采用一份无外部依赖的 Node 接入助手：对客户端只暴露标准 stdio MCP，对 CoNest 使用现有的认证 HTTP MCP。客户端名称、命令语法和路径由接收提示词的本地 AI 处理；网页维持一个主要接入流程。此版本没有发布或要求安装第三方 npm 连接器包。

## 凭证与授权

- 提示词仅含短期、随机配对码和接入助手源代码的 SHA-256，不含长期 CoNest 凭证、模型密钥或客户端登录信息。
- 助手在本机生成高熵凭证，只把 SHA-256 散列提交为连接申请。服务端批准后登记散列，不生成或保存凭证明文。
- 主人必须在网页确认；窃取短期码只能抢占待确认申请，不能直接获得项目访问权限。用户应核对本机助手与网页的指纹，自报客户端名称不是可信身份证明。
- 每次配对生成独立凭证，已有凭证继续有效。网页“取消本次连接”仅撤销这一凭证，正在等待的事件读取也会重新校验；撤销整个 AI 则使它的所有凭证失效。
- 新凭证继承该 AI 现有的项目权限，不是更细的只读授权。确认面板明确告知访问范围。需要更细的工具范围，仍需后续服务端权限设计。

`examples/pair.mjs` 的 `pair` 模式从 stdin 接收 JSON，在 `~/.config/conest/connections/` 的独立目录保存权限为 0600 的配置和凭证文件；凭证不进入命令参数、stdout 或诊断日志。`proxy --config /absolute/path/connection.json` 模式只转发 MCP 消息，HTTP 请求携带本地凭证，拒绝跨站重定向，并检查项目和 AI 身份。它不启动模型、没有本地目录工具，也不读取客户端的登录凭证。

## 连接与自动回复分开验证

“已复制”“已授权”“收到 MCP 请求”分别表示不同阶段。页面只显示服务端实际收到的申请和连接记录，不能据此宣称本地模型正在运行。

本次统一的是**身份授权和工具接入**。自动回复仍由现有持续运行的连接器负责，需要单独检查客户端运行能力、模型调用、队列消费和停止命令。安装提示词要求在未验证持续进程时报告“工具已连接，自动回复未启用”。本次测试没有运行真实 Codex / Claude 模型、使用用户订阅或产生模型费用。

私人工作目录默认关闭；需要时在高级设置中按[本地工作目录说明](local-workspace.md)单独授权和隔离。stdI/O 桥接不会自动挂载这些能力。

## 接口与验证

| 接口                                             | 授权与行为                                       |
| ------------------------------------------------ | ------------------------------------------------ |
| `POST /api/projects/:p/agents/:a/pairings`       | 人类登录、项目成员、AI 主人；生成十分钟配对码    |
| `GET /api/projects/:p/agents/:a/pairings/latest` | 同样的主人检查；恢复最近申请，不返回配对码       |
| `GET /api/connect/requests/:id`                  | 主人读取申请状态、指纹和收到 MCP 请求的时间      |
| `PATCH /api/connect/requests/:id`                | 主人确认或取消，不接受其他成员代为操作           |
| `POST /api/connect/claim`                        | 公共但限流；使用配对码绑定一次本机生成的凭证散列 |
| `POST /api/connect/poll`                         | 申请客户端用其生成的凭证证明身份，只读取审批状态 |
| `GET /api/connect/bootstrap`                     | 无凭证的公共接入助手代码；按提示词中的散列校验   |

回归测试覆盖主人权限、确认前拒绝访问、一次性与过期、重发取消、刷新恢复、跨域拒绝、单连接撤销、全 AI 撤销、长轮询撤权，以及下载助手配对、真实 MCP 工具发现/项目读取和 Unicode 内容桥接。兼容性的验证对象是 MCP 协议客户端；各品牌实际安装流程仍由本机客户端验证。
